# Atelier Nova — gestion des réservations
Mini-application pédagogique HTML / CSS / JavaScript.

## Lancer le projet
Ouvrir `index.html` dans un navigateur. Aucune installation nécessaire.

## Fonctionnalités
- Ajouter une réservation (client, prestation, date)
- Afficher, rechercher et supprimer une réservation
- Conserver les données dans le localStorage

Les branches et commits du dépôt sont préparés pour le TP Git avancé.
